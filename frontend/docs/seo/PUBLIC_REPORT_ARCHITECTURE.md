1. URL STRUCTURE
==================================================
- **Format**: `chronicle.finance/reports/[slug]-[id]`
- **Slugs**: Should contain keywords (e.g., `compound-interest-simulation-retirement`).

==================================================
2. INDEXING RULES
==================================================
- **Public by Default**: All simulations generated by users are public unless marked "Private" (Premium feature).
- **Robots.txt**: Block indexing of simulations with < 1 minute session duration (low value).

==================================================
3. DYNAMIC CONTENT
## - Reports are hydrated with the same AI insight and visualization state as the live workspace.
- **Search Intent**: Designed to answer "What if..." financial questions.

==================================================
4. AD REVENUE (Future)
==================================================
- Public reports can serve as high-quality landing pages for relevant financial services (ad-supported tier).
