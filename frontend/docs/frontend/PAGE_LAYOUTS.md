==================================================
1. THE MASTER GRID
==================================================
- **System**: 12-column CSS Grid.
- **Gutter**: 32px (Desktop) / 16px (Mobile).
- **Margin**: 5% auto.

==================================================
2. TEMPLATE: THE FRONT PAGE (Home)
==================================================
- **Header**: Sticky Navbar (Thin).
- **Hero**: Span 12, large typography, ambient background.
- **Featured Model**: Span 8 (Main view), Span 4 (Quick info).
- **Editorial Grid**: Multi-column section for secondary models and vision.

==================================================
3. TEMPLATE: THE WORKSPACE (Simulation)
==================================================
- **Sidebar**: Span 3 (Sticky).
- **Viewport**: Span 9 (The Bubble System).
- **Bottom Shelf**: Span 12 (Insight Panel and Timeline).

==================================================
4. TEMPLATE: THE EDITORIAL REPORT (Output)
==================================================
- **Masthead**: Centered title, date, and metrics.
- **Body**: 2-column newspaper layout.
- **Sidebars**: Pull quotes and AI insights.

==================================================
5. RULE OF "NEGATIVE SPACE"
==================================================
- Never fill the entire height of the screen with content.
- Use empty columns to create asymmetric balance and focus.
