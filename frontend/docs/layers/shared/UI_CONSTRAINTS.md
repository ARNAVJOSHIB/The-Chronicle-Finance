==================================================
1. PURPOSE OF THIS DOCUMENT
==================================================

This document defines the strict constraints required to maintain the Chronicle Finance "Quiet Luxury" newspaper aesthetic.

It serves as a "Hard Stop" for design drift.

==================================================
2. THE "EDITORIAL SQUEEZE" RULE
==================================================

Chronicle Finance is NOT a dashboard. 
- **Rule**: Avoid the "Dashboard Grid" (uniform boxes filling the screen).
- **Action**: Use asymmetric layouts and varying column widths to simulate a newspaper front page.

==================================================
3. TYPOGRAPHY CONSTRAINTS
==================================================

- **Serif Only for Impact**: Headlines, pull quotes, and AI insights must use Serif.
- **Sans Only for Data**: Numbers, labels, and form fields must use Sans.
- **No Mixing**: Do not use Serif for small functional labels (e.g., "Submit").
- **Contrast**: Maintain a 4.5:1 minimum contrast ratio, even on parchment backgrounds.

==================================================
4. COLOR RESTRAINT
==================================================

- **Max 3 Hues**: The interface should primarily use Ivory, Charcoal, and ONE accent color (e.g., Financial Green) at a time.
- **No Pure Blacks**: Use Charcoal (#1A1A1A) for text.
- **No Pure Whites**: Use Parchment (#F9F7F2) for backgrounds.

==================================================
5. SPACING AND "BREATHING ROOM"
==================================================

- **Gutter Rules**: Use a strict 24px or 32px gutter system.
- **Margin Max**: Never allow content to touch the edge of the viewport.
- **White Space**: 30% of the screen should be "empty" to maintain a premium feel.

==================================================
6. INTERACTIVE CONSTRAINTS
==================================================

- **Animations**: Max duration 0.5s. Ease-in-out only. No "bouncy" spring physics except for the Bubble System.
- **Buttons**: Minimum height 44px. No rounded corners greater than 2px (keep them sharp/architectural).

==================================================
7. FORBIDDEN ELEMENTS
==================================================

- No "Cyberpunk" glows or neon effects.
- No "3D Card" tilts on hover.
- No "Gamified" progress bars (use editorial timelines instead).
- No generic emojis in the UI.

==================================================
END OF DOCUMENT
