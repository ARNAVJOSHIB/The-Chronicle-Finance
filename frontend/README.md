# Chronicle Finance

Chronicle Finance is a web-based financial simulation platform designed to transform traditional financial models into interactive visual experiences.

## Features

- Compound Interest Simulation
- Discounted Cash Flow Simulation
- Monte Carlo Simulation

## Tech Stack

- Next.js 16.2.5
- Python FastAPI
- PostgreSQL

## Installation

### Prerequisites

- Python 3.9+
- Node.js 14+
- PostgreSQL 13+

## Backend Setup

1. Navigate to the backend directory:
```
cd backend
```

2. Create a virtual environment:
```
python -m venv venv
```

3. Activate the virtual environment:
```
# On Windows
venv\Scripts\activate

# On Mac/Linux
source venv/bin/activate
```

4. Install the required packages:
```
pip install -r requirements.txt
```

5. Start the server:
```
python server.py
```

## Frontend Setup

1. Install the required dependencies:
```
npm install
```

2. Start the development server:
```
npm run dev
```

The application will be available at `http://localhost:3000`.
