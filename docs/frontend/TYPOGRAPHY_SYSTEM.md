==================================================
1. FONT FAMILIES
==================================================
- **Editorial (Serif)**: `Playfair Display`.
  - Used for: Main headlines, large quotes, AI Insights.
  - Weights: Regular (400), Italic (400), Bold (700).
- **Utility (Sans)**: `Inter`.
  - Used for: UI Labels, Inputs, Body text, Data points.
  - Weights: Light (300), Regular (400), Medium (500).
- **Data (Mono)**: `IBM Plex Mono`.
  - Used for: Code-like data, specific simulation metadata.

==================================================
2. SCALE (Mobile / Desktop)
==================================================
- **Hero Title**: 3.5rem / 6rem (Serif)
- **Section Title**: 2rem / 3.5rem (Serif)
- **Sub-headline**: 1.25rem / 1.75rem (Serif)
- **Body Text**: 1rem / 1.125rem (Sans)
- **Utility Label**: 0.75rem / 0.875rem (Sans)

==================================================
3. RHYTHM AND LINE HEIGHT
==================================================
- **Body**: 1.6 (Editorial breathability).
- **Headlines**: 1.1 (Compact authority).
- **Data**: 1.2 (Clarity).

==================================================
4. RULES OF USE
==================================================
- No "All Caps" on Serif headlines (too aggressive).
- No letter-spacing on Serif (keep the natural kerning).
- Max line-width for readability: 65 characters (720px).
